# Contributing to Omni-Hunt

Thank you for your interest in improving Omni-Hunt.

This project is intended for ethical security research, educational use, and authorized testing demonstrations. Contributions that improve documentation, structure, usability, and clarity are welcome.

---

## How to Contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Validate the project locally
5. Open a pull request with a clear summary

Example:

```bash
git checkout -b feature/your-improvement
```

---

## Contribution Standards

- Keep code readable and maintainable
- Follow Python best practices and clean naming conventions
- Document new features clearly
- Avoid committing sensitive or personal data
- Ensure changes remain aligned with the project’s ethical purpose

---

## Reporting Issues

Please include:
- a clear description of the issue
- reproduction steps
- environment details
- expected vs. actual behavior

---

## Security and Ethics

Do not submit or endorse malicious code, credential harvesting workflows, or unauthorized testing materials. All contributions should remain aligned with responsible cybersecurity research and legal compliance.
